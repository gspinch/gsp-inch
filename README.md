# GSP·INCH — лендинг «Поступление в Китай»

Лендинг + админка (отзывы, результаты, услуги/цены, FAQ, заявки, настройки метрик).
Стек: Node.js 22, Express, EJS (серверный рендер, удобно для SEO), SQLite. Деплой: Docker + Caddy (HTTPS сам).

```
src/server.js     — сервер, API заявок, админка
src/db.js         — схема БД и описание полей админки (добавить поле = дописать строку)
views/            — шаблоны страниц (index.ejs — лендинг, admin/* — админка)
public/           — CSS, JS, картинки
data/             — база site.db и загруженные фото (создаётся автоматически, НЕ в git)
```

## Запуск локально

```bash
npm install
```

```bash
cp .env.example .env   # и впишите ADMIN_PASSWORD
```

```bash
npm run dev
```

Сайт: http://localhost:3000, админка: http://localhost:3000/admin

## 1. Покупка домена

Регистраторы: **reg.ru**, **nic.ru**, **2domains.ru** (оплата российской картой). Зона `.ru` ≈ 200–900 ₽/год, `.com` ≈ 1500–2500 ₽/год.
Варианты имени: `gspinch.ru`, `gsp-inch.ru`, `kamila-china.ru`, `postuplenie-china.ru` — свободу проверьте на сайте регистратора.

⚠️ Домен оформляйте **на заказчицу** (её паспортные данные), а вас добавьте как доверенное лицо — так он не потеряется.

## 2. Сервер (VPS)

Оператор — ИП в Казахстане, поэтому сервер в **Казахстане** (Закон РК «О персональных данных и их защите»: данные хранятся на территории РК).
Выбран VPS **hostlab.kz**, тариф «Лайт»: 1 CPU / 2 ГБ RAM / 40 ГБ, Ubuntu 22.04/24.04.

При создании выберите образ **Ubuntu 24.04** (у Timeweb есть готовый образ «Docker» — тогда пропустите установку Docker).

## 3. DNS

В панели регистратора домена добавьте записи (IP — адрес вашего VPS):

| Тип | Имя | Значение |
|-----|-----|----------|
| A   | @   | IP сервера |
| A   | www | IP сервера |

Обновление DNS занимает от 15 минут до нескольких часов.

## 4. Деплой

Подключитесь к серверу (`ssh root@IP`) и выполните:

```bash
curl -fsSL https://get.docker.com | sh
```

Загрузите проект (через git или scp с вашего компьютера):

```bash
scp -r gsp-inch root@IP:/root/
```

```bash
cd /root/gsp-inch && cp .env.example .env && nano .env
```

В `.env` укажите `SITE_URL=https://ваш-домен.ru`, `DOMAIN=ваш-домен.ru`, длинный `ADMIN_PASSWORD` и `SESSION_SECRET` (сгенерировать: `openssl rand -hex 32`). Затем:

```bash
docker compose up -d --build
```

Через минуту сайт откроется по `https://ваш-домен.ru` (сертификат Caddy выпустит сам, когда DNS уже указывает на сервер).

**Обновление сайта** после правок кода: загрузить файлы заново и выполнить `docker compose up -d --build`. База и фото в `data/` при этом сохраняются.

**Бэкап:** `crontab -e` → строка `0 4 * * * /root/gsp-inch/backup.sh` (архивы в `backups/`, хранятся 14 последних).

## 5. Админка

`https://ваш-домен.ru/admin`, пароль из `.env`.

- **Заявки** — всё, что приходит с формы; можно отмечать обработанными и выгрузить в Excel (CSV).
- **Результаты студентов / Отзывы** — добавить, отредактировать, скрыть, поменять порядок, загрузить фото (сожмётся автоматически).
- **Услуги и цены**, **Частые вопросы** — то же самое.
- **Настройки** — цифры (9 лет / 100+ / 5/5), ссылки на соцсети, коды метрик, Telegram-уведомления.

### Уведомления о заявках в Telegram
1. В Telegram написать **@BotFather** → `/newbot` → получить токен.
2. Написать своему боту любое сообщение, затем открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id": ...}`.
3. Вставить токен и chat id в админке → Настройки.

## 5.1. Английская версия

Сайт двуязычный: русский на `/`, английский на `/en` (переключатель RU/EN в шапке, для поисковиков стоят теги hreflang, обе страницы в `sitemap.xml`).
В админке у каждого текстового поля есть пара «— English». Если английское поле пустое, на `/en` показывается русский текст.
Тексты интерфейса (заголовки, кнопки, форма) лежат в `src/i18n.js`. В заявке с английской версии в поле UTM будет пометка `lang=en`.

## 6. Метрики

### Яндекс.Метрика
1. https://metrika.yandex.ru → «Добавить счётчик», адрес сайта, включить **Вебвизор**.
2. Скопировать **номер счётчика** (только цифры) → админка → Настройки → «Яндекс.Метрика».
3. Цели (Метрика → Цели → «JavaScript-событие»), идентификаторы уже отправляются сайтом:

| Идентификатор | Что значит |
|---|---|
| `lead` | **отправлена заявка** (главная цель) |
| `cta_hero`, `cta_header`, `cta_services` | клик по кнопкам «Записаться» |
| `service_open` | открыта карточка услуги |
| `telegram_click`, `social_telegram` и т.п. | переход в мессенджер/соцсети |

### Google Analytics 4 (по желанию)
analytics.google.com → создать ресурс → поток «Веб» → скопировать `G-XXXXXXX` в админку. Событие `lead` отметить как ключевое.

**UTM-метки** из рекламы автоматически сохраняются в заявке (видно в админке).

## 7. Поисковые системы

### Яндекс.Вебмастер
1. https://webmaster.yandex.ru → добавить сайт `https://ваш-домен.ru`.
2. Способ подтверждения **«Мета-тег»** → скопировать значение `content="…"` → админка → Настройки → «Яндекс.Вебмастер» → сохранить → «Проверить».
3. Индексирование → Файлы Sitemap → добавить `https://ваш-домен.ru/sitemap.xml`.
4. Информация о сайте → Региональность → Россия; добавить сайт в **Яндекс Бизнес** (бесплатно) для доп. трафика.

### Google Search Console
1. https://search.google.com/search-console → «Префикс URL» → `https://ваш-домен.ru`.
2. Подтверждение «HTML-тег» → значение `content` → админка → Настройки → «Google Search Console».
3. Файлы Sitemap → `sitemap.xml`.

Уже настроено в коде: title/description, OpenGraph-превью для мессенджеров, canonical, `robots.txt`, `sitemap.xml`, микроразметка Schema.org (услуги с ценами + FAQ — может показываться прямо в выдаче), админка закрыта от индексации.
